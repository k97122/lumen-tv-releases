# Lumen TV

A TV guide and player for Android TV and Amazon Fire TV, for use with your own Xtream Codes–compatible IPTV subscription.

Lumen TV doesn't include or provide any channels, films or other content. You need your own provider's server address, username and password.

## Install with Downloader

1. Install **Downloader** (by AFTVnews) from the Amazon Appstore or Google Play.
2. Allow Downloader to install apps:
   - **Fire TV:** Settings → My Fire TV → Developer options → Install unknown apps → Downloader → On. If you can't see Developer options, open Settings → My Fire TV → About and press OK on the device name 7 times.
   - **Google TV / Android TV:** Settings → Apps → Security & restrictions → Unknown sources → Downloader → On.
3. Open Downloader, enter the code **9717570** and press Go. Or enter the full link:

   ```
   https://github.com/k97122/lumen-tv-releases/releases/latest/download/lumen-tv.apk
   ```

4. Choose **Install** when the download finishes, then **Open**.
5. Sign in with your provider's server address, username and password.

Lumen TV appears with your other apps. It doesn't change your home screen or replace your launcher.

## Updating

Install the newer version over the top using the same link. Your sign-in, favourites and history are kept.

## Requirements

- Android TV, Google TV or Fire TV running Android 8.0 or newer (Fire OS 7 or newer).
- An Xtream Codes–compatible provider account.

## Privacy

- Your provider details are stored encrypted on your device and are only sent to your provider.
- Lumen TV has no account system, analytics or tracking.
- Online subtitles are optional and use your own OpenSubtitles API key.
